# Actually Hang

AI-powered IRL meetup coordination for NYC. Hackathon MVP.

## Run

1. Copy `env.txt` to `.env.local` and set:
   - `NEXT_PUBLIC_MAPBOX_ACCESS_TOKEN` (map)
   - `TAVILY_API_KEY` (AI enhance)
   - `OPENAI_API_KEY` (AI enhance)
2. `npm install` then `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000)
